# Fazendo exemplos básicos de Python

Repositório com exercícios e exemplos introdutórios de Python, focados em aprender fundamentos da linguagem e lógica de programação.

## O que tem aqui
- **Condição**: estruturas condicionais e variações (ternária, alinhamento etc.)
- **Entrada/Saída**: uso de `print` e `input`
- **Introdução**: primeiro programa e organização de blocos
- **Operadores**: aritméticos, comparação, lógica, atribuição e identidade
- **Strings**: fatiamento, métodos úteis e testes
- **Repetição**: `for`, `while` e variações
- **Variáveis e tipos**: conversões, interpolação e tipos de dados
- **POO (básico)**: exemplos de herança, encapsulamento e polimorfismo

## Como rodar
Execute qualquer arquivo `.py` diretamente:

```bash
python "nome_do_arquivo.py"
```

## Observações
- Cada script é um exemplo isolado (didático).
- Se houver algum exercício/desafio no título, o arquivo geralmente já contém a lógica completa.
