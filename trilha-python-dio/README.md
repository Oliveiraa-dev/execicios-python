# Trilha Python DIO

Repositório para exercícios e exemplos da trilha de Python (DIO), cobrindo fundamentos, estruturas de dados, POO, decorators e tópicos de APIs/Back-end.

## O que tem aqui
- **00 - Fundamentos**: operadores, variáveis, condicionais e repetição
- **01 - Estrutura de dados**: listas, tuplas, conjuntos e dicionários
- **02 - Programação Orientada a Objetos**: classes, herança, encapsulamento e polimorfismo
- **03 - Decoradores, Iteradores e Geradores**
- **04 - Data e hora**
- **05 - Manipulação de arquivos**
- **06 - Gerenciamento de pacotes e boas práticas**
- **07 - Banco de dados**
- **11 - Desenvolvimento de APIs com Flask**
- **12 - Desenvolvimento fullstack com Django**
- **13 - APIs Assíncronas com FastAPI**

## Como usar
- Cada pasta contém exemplos/arquivos .py do módulo.
- Para executar um script, rode o arquivo desejado com:

```bash
python "nome_do_arquivo.py"
```

## Organização
- O repositório está estruturado por módulos (pastas numeradas).
- Desafios aparecem dentro das pastas de cada módulo quando aplicável.
